# Pack of Five repository guidance

- Read `ROADMAP.md` before choosing the next task. Update it when implementation, deployment, testing, or product decisions change.
- Track local implementation, GitHub updates, Cloudflare deployment, Neon migrations, and live verification separately. Record a live result only when observed or confirmed by the user.
- Include copyable repository-relative GitHub paths and clickable local file links in file handoffs. State which files go to GitHub, Neon, or both. Number instructions when there are more than three steps.
- Preserve organization boundaries and existing audit history. Test access changes with separate test accounts and sample records.
